# Banking System – Account Management REST API

A RESTful backend for managing bank accounts, built with **Spring Boot** and **PostgreSQL** using a layered architecture (Controller → Service → Repository → Entity).

![Java](https://img.shields.io/badge/Java-17-orange) ![Spring Boot](https://img.shields.io/badge/Spring%20Boot-4.0-brightgreen) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-database-blue)

> **Note:** This is a learning project. All data used for testing is fictional.

## Features
- Create, read, update and delete bank accounts
- Search accounts by account number or by branch
- Account details: holder name, IFSC code, mobile, email, account type, branch, status and balance
- **Deposit, withdraw and fund transfer**, with the whole transfer running in one database transaction (`@Transactional`), so it fully succeeds or fully rolls back
- **Transaction history** for every account, recorded automatically on each money movement
- **Concurrency safe:** accounts are row-locked (`PESSIMISTIC_WRITE`) during a transaction, always in account-number order to avoid deadlocks
- **Money stored as `BigDecimal`** (never `double`), limited to 2 decimal places
- **Global exception handling** returning clean JSON errors instead of stack traces
- Unit tests (JUnit 5 + Mockito) covering deposit, withdraw, transfer and the failure cases
- Proper HTTP status codes: `201 Created`, `404 Not Found`, `409 Conflict` for duplicate account numbers
- Spring Data JPA derived queries, with the schema auto-generated by Hibernate

## API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/accounts` | List all accounts |
| GET | `/api/accounts/{accountNumber}` | Get one account |
| GET | `/api/accounts/branch/{branch}` | Accounts in a branch |
| POST | `/api/accounts` | Open an account (409 if the number exists) |
| PUT | `/api/accounts/{accountNumber}` | Update an account |
| DELETE | `/api/accounts/{accountNumber}` | Close an account |
| POST | `/api/accounts/{accountNumber}/deposit` | Deposit money |
| POST | `/api/accounts/{accountNumber}/withdraw` | Withdraw money (rejected if balance is too low) |
| POST | `/api/transfer` | Transfer between two accounts (atomic) |
| GET | `/api/accounts/{accountNumber}/transactions` | Transaction history, newest first |

> The balance can only change through deposit, withdraw and transfer, so every movement appears in the history. Operations require the account status to be `Active`.

**Deposit / withdraw body**
```json
{ "amount": 1500.50 }
```

**Transfer body**
```json
{ "fromAccount": 100200300, "toAccount": 100200301, "amount": 750.00 }
```

**Error response (example)**
```json
{
  "timestamp": "2026-10-07T17:05:12",
  "status": 422,
  "error": "Unprocessable Entity",
  "message": "Insufficient balance in account 100200300"
}
```

**Sample request body**
```json
{
  "accountNumber": 100200300,
  "accountHolderName": "Arun Kumar",
  "IFSCCode": "TEST0001234",
  "mobileNumber": 9000000000,
  "emailID": "arun@example.com",
  "accType": "Savings",
  "aadhaarNo": 111122223333,
  "branch": "Chennai",
  "status": "Active",
  "balance": 5000.00
}
```

## Getting Started
**Prerequisites:** JDK 17+, PostgreSQL

1. Clone the repo
   ```bash
   git clone https://github.com/Gokulkrish24/banking-system-api.git
   cd banking-system-api
   ```
2. Create the database
   ```sql
   CREATE DATABASE bank_records;
   ```
3. Set your credentials as environment variables
   ```bash
   export DB_USERNAME=postgres
   export DB_PASSWORD=your_password
   # optional: export DB_URL=jdbc:postgresql://localhost:5432/bank_records
   ```
4. Run the tests
   ```bash
   ./mvnw -Dtest=AccountServiceImplTest test
   ```
5. Run the app
   ```bash
   ./mvnw spring-boot:run
   ```
   The API starts at `http://localhost:8080`.
